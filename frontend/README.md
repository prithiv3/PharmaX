# Frontend - Pharmacy Substitution Decision Support System

Minimal React + Vite frontend for the Pharmacy Substitution Decision Support System prototype.

## Architecture
- `src/components/`: Reusable UI components (`Header`, `Navigation`, `HealthStatusCard`).
- `src/pages/`: Page views (`HomePage`).
- `src/services/`: API integration services (`api.js`).
- `src/hooks/`: Custom React hooks (for future state management).
- `src/utils/`: Formatting and helper utilities (for future modules).

## Setup & Execution
1. Install node dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
   The application will start at `http://localhost:5173`.
